## Integration and acceptance boundaries

[AeroveLite(meow).js](AeroveLite%28meow%29.js), generated by shared `tools/generate-meow.js`, uses the `main(config)` object interface above. JS preserves host-provided DNS, hosts, TUN, ports, sniffing, mode, and controller settings. Pure remote providers must be flattened first. Subscription rule-set dependencies in DNS are explicitly rejected; failures preserve the original input.

Outstanding work in this historical snapshot included wiring the Meow validator into import, resource preparation, and runtime paths; admitting direct logical rules; executing JS in a real APK and reading back final YAML; and validating MRS/residual updates, ads, direct traffic, non-China traffic, and service exits. Subsequent completion must be established from newer AEROVE session source, effective configuration, APKs, and logs, not inferred from this snapshot.

Standard AEROVE uses Mihomo. See [official core/client evidence](../Meow/REFERENCE-meow-rs.md) for the official meow-rs core, official Android/iOS native-YAML interfaces, and core validation. AEROVE’s QuickJS interface is not attributed to official apps.
