## <a id="choose"></a>Choose by use case

| Use case | Choice and limits |
| --- | --- |
| Smart route selection | [Clash Party](../../Mihomo内核系/Clash%20Party/README.md) Smart: requires the Smart core and LightGBM; consumes fused rule sets. |
| Standard Mihomo | [Clash Party](../../Mihomo内核系/Clash%20Party/README.md) Normal / [FlClash](../../Mihomo内核系/FlClash/README.md): equivalent routing semantics, with url-test regional groups. Use Normal by default for Clash Verge Rev. |
| Android Mihomo | [CMFA](../../Mihomo内核系/Clash%20Meta%20For%20Android/README.md): native YAML; a synchronized output, not the rule authority. |
| Official Meow / meow-rs | [Meow](../../Meow内核系/Meow/README.md): native YAML; replace the node-subscription placeholder URL first. Core configuration checks passed; official Android/iOS import and connections remain unverified. |
| AEROVE Lite (development integration) | [AEROVE Lite](../../Meow内核系/Aerove%20Lite/README.md): JS override with nodes expanded first. Production Meow validation is connected, and the new shards passed the fixed Rust reader and the app’s unchanged header/entry budget checks. Full-resource retesting with the fixed APK and real routing remain pending. |
| Stash | [Stash](../../独立内核系/Stash/README.md): generated by trimming CMFA output for Clash Premium compatibility. |
| Karing | [Karing](../../Sing-box内核系/Karing/README.md): adapts direct / block / currentSelected in source order. Configure node groups, DNS, and the default action in the app. |
| sing-box / Hiddify / HomeProxy | [sing-box](../../Sing-box内核系/SingBox/README.md): choose for the actual 1.14 or 1.13 core; full-configuration import limits in GUIs require separate validation. |
| v2rayN Xray | [v2rayN](../../Xray内核系/v2rayN/README.md): 78 nonempty fused SRS assets are flattened into 98 Xray routing rules. |
| Other Apple clients | [Egern](../../独立内核系/Egern/README.md) / [Shadowrocket](../../独立内核系/Shadowrocket/README.md) / [Surge](../../独立内核系/Surge/README.md) / [Loon](../../独立内核系/Loon/README.md) / [Quantumult X](../../独立内核系/Quantumult%20X/README.md): use each app’s native syntax. |
| OpenWrt | [OpenClash](../../Mihomo内核系/OpenClash/README.md) is the primary entry. [Passwall](../../双内核系/Passwall/README.md) / [Passwall2](../../双内核系/Passwall2/README.md) are fallback references; their 78 fused SRS entries are only for the sing-box routing backend. |

### <a id="conditions"></a>Conditions and evidence

The following conditions correspond to the matrix footnotes:

- **¹ v2rayN**: switch to the mihomo core.
- **² Surge Hysteria 2**: iOS 5.8.0+ / Mac 5.4.0+.
- **³ Smart**: vernesong Smart branch plus JS override; MetaCubeX Alpha is not Smart.
- **⁴ Stash Snell**: the referenced Wiki example uses v3; v4 requires actual app testing.
- **⁵ Surge AnyTLS**: iOS 5.17.0+ / Mac 6.4.3+.
- **⁶ Loon AnyTLS**: 3.3.9+.
- **⁷ Quantumult X AnyTLS**: 1.6.0+.

[Official evidence and unverified items](../upstream/2026-10-19/apple/report.md).


The Clash Party category includes Clash Party, Clash Verge Rev, and Mihomo Party. CMFA means Clash Meta For Android, including the [ClashMi](https://github.com/KaringX/clashmi) usage entry. QX means Quantumult X. The v2rayN mihomo column describes only the mihomo core; it does not imply that sing-box supports SSR or Snell.

<a id="常见选择"></a>
### Common choices

For common protocols (SS / VMess / Trojan), choose by device. For VLESS + REALITY, consider Mihomo / sing-box / SR / Loon / v2rayN. For Hysteria 2 / TUIC, avoid older Surge versions, QX, and Xray. **LightGBM automatic selection** requires Clash Party or OpenClash with the Smart Alpha core.

<a id="其他导入边界"></a>
### Other import boundaries

ShellCrash (formerly ShellClash, in mihomo mode) can use CMFA YAML, but inspect overrides after startup. HomeProxy generates configuration through UCI; full JSON import has not been validated. Stash and Egern use their respective YAML files. Passwall / Passwall2 fused SRS fallbacks apply only to sing-box routing nodes. Happ routing profiles differ from v2rayN RuleObject arrays, so this repository’s Xray JSON cannot be imported directly into Happ. See the [additional consumer review](../upstream/2026-10-19/consumers/report.md) and individual client guides.


For complete setup entry points, see [Downloads and import](downloads.md). For platform DNS behavior and post-import checks, see [DNS and runtime verification](dns-and-verification.md).
