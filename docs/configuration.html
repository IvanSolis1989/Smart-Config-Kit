SMART CONFIG KIT / 离线配置

让配置适合你的使用方式

选择业务方案，直接下载 FlClash 脚本；其他客户端可下载设置文件。页面无需联网，也不会自动应用到设备。

本地 JS 参数

设置测速、QUIC 和订阅适配等选项；下载的 FlClash 脚本会同时包含当前业务方案和这些参数。

全端业务

选择保留专属规则与策略组的业务。下载的 FlClash 脚本同时包含本地 JS 参数页的选择。

完整保留全部业务；精简使用预设；自选可逐项配置。

保留的业务

广告、安全、直连等基础保护保留；未选业务继续匹配后续基础规则。

下载与使用

JSON 仅导出当前标签的独立设置，不包含另一标签的选择。

导入 FlClash

  1. 打开下载的 JS，复制全文。
  2. 创建独立命名的「粘贴」覆写。
  3. 关联订阅并关闭 DNS 覆写。
设置 JSON 的命令行用途

本地参数 JSON：

node tools/configure.js --settings settings.json --target local.js

业务 JSON（其他客户端）：

node tools/configure.js --settings settings.json --output-dir <全新目录>

可先加 --dry-run 检查。

页面不会读取个人文件、运行脚本或验证设备。
