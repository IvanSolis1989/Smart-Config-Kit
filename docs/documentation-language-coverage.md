# Documentation language coverage

[Project home](../README.md) · [Documentation](README.md) · [Licensing notice](disclaimer.md)

## Default and explicit choices

User-facing README files, client references, guides, research and acceptance reports, and historical design documents use English at their existing paths. Separate `.zh-CN.md` editions provide an explicit Chinese choice. The configuration page and generated navigation images default to English. Browser locale does not silently change the configuration page; its **中文** control is explicit. Issue replies continue to follow the language of the question.

All 20 CHANGELOG files contain complete English entries, rather than English indexes pointing to Chinese histories. There are no separate Chinese CHANGELOG editions. Dates, original entry structure, source links and historical anchors are retained; translation does not turn past assertions into new test results or guarantees.

This is a presentation change, not a change to routing policy, configuration identifiers, client compatibility or historical acceptance outcomes. Configuration exports do not change when the display language changes.

## Preserved evidence and maintenance instructions

`AGENTS.md` is an executable maintenance contract, not user documentation. It remains unchanged and authoritative. Original upstream response bodies, manifests, third-party license/source notices and factual evidence are retained in their original form. Translated reports provide a readable account without rewriting their source evidence.

Literal configuration keys, policy-group names, paths, code samples and source quotations can contain non-English text where accuracy requires it. Their presence is not a promise that the underlying runtime configuration has been renamed. Legacy download paths remain available until a separately validated compatibility migration can preserve existing clients.

## Maintenance checks and limits

The README pair manifest checks inventory, explicit language navigation and reviewed file hashes. It detects unreviewed single-sided changes but does not prove semantic equivalence. Translation review must cover both editions before updating a receipt. Generated SVG catalogs have a strict English-output check. The documentation renderer includes both language editions and historical pages while excluding raw upstream payloads and maintenance contracts.

Local structural, link and regression checks do not constitute published CI success, browser visual acceptance, Pages deployment or client/device acceptance. Those outcomes must be reported separately after they have actually occurred.
