# 文档语言覆盖范围

[项目首页](../README.zh-CN.md) · [文档](README.zh-CN.md) · [许可说明](disclaimer.zh-CN.md)

## 默认语言与主动选择

面向用户的 README、客户端参考、指南、研究及验收报告、历史设计文档均在原路径提供英文版，并以独立 `.zh-CN.md` 文件提供主动选择的中文版本。配置页面和生成导航图片默认英文。浏览器语言不会自动切换配置页面；需要显式选择 **中文**。Issue 回复仍按问题语言进行。

全部 20 份 CHANGELOG 都是完整英文条目，不再以英文索引代替历史正文，也没有独立中文 CHANGELOG。原日期、条目结构、来源链接和历史锚点保留；翻译不会将过去的断言转化为新的测试结果或保证。

这是展示层变更，不改变分流策略、配置标识、客户端兼容性及历史验收结果。切换显示语言不会改变配置导出内容。

## 保留证据与维护指令

`AGENTS.md` 是执行性维护约束，不属于用户文档；保留原样且继续具有权威性。原上游响应正文、清单、第三方许可及来源说明、事实证据均保留原始形式。翻译后的报告提供可读说明，不重写来源证据。

必要的配置键、策略组名、路径、代码示例、来源引文可以保留非英文原文以确保准确。这不意味着底层运行配置已经改名。旧下载路径仍保留，直到独立验证的兼容迁移能确保现有客户端继续使用。

## 维护检查与限制

README 配对清单检查覆盖范围、显式语言入口和已审核的文件哈希，可发现未经审核的单侧变更，但不能证明翻译语义等价。更新记录前必须审核两个版本。生成 SVG 有严格英文输出检查。文档渲染器覆盖双语文档及历史页面，同时排除上游原始载荷和维护指令。

本地结构、链接和回归检查不等于远端 CI 通过、浏览器视觉验收、Pages 部署或客户端/真机验收。只有这些步骤实际发生后才能分别报告完成。
