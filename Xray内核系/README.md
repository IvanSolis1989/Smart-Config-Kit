# Xray clients

This family provides routing-rule JSON for v2rayN when it uses the Xray core. v2rayN supports multiple cores; if you use Mihomo or sing-box, choose a configuration from that family instead. The Xray JSON contains routing settings only, with `proxy`, `direct`, and `block` exits.

- [v2rayN](./v2rayN/README.md) — Choose Mihomo, sing-box, or Xray routing files for the active core

Confirm the active core in v2rayN before importing its corresponding file. Do not treat Xray routing JSON as a complete proxy configuration.
