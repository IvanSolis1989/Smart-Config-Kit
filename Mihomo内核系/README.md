# Mihomo clients

Configurations and override scripts for Clash Party, Clash Meta For Android (CMFA), OpenClash, and FlClash. Clash Party Smart uses capabilities of the Smart core; import methods and actual capabilities are documented in each client guide.

## Client guides

- [Clash Party / Clash Verge / Mihomo Party](./Clash%20Party/README.md) — Smart and Normal override scripts
- [Clash Meta For Android (CMFA)](./Clash%20Meta%20For%20Android/README.md) — Mihomo YAML configuration
- [OpenClash](./OpenClash/README.md) — Smart and Normal configurations
- [FlClash](./FlClash/README.md) — Mihomo override script

Import the configuration or script through the entry for your actual client. The download directory maps each client to its files; similar configuration formats do not imply identical import steps.
