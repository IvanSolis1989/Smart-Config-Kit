# sing-box 内核系客户端入口

本系列提供 sing-box 完整配置和 Karing 原生分流规则入口。Karing 文件仅用于自定义分流规则；节点组、DNS 和最终默认动作由 Karing App 设置，不能作为完整 sing-box 配置导入。Hiddify 与 HomeProxy 的 sing-box 导入说明见 [SingBox 教程](./SingBox/README.md)。
